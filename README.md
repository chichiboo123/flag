# FLAG 프로젝트

세계 여러 나라의 국기를 **색상 중심으로 탐색**하고, 교육 활동에 바로 활용 가능한 팔레트를 만드는 웹 앱 프로젝트입니다.

- 앱 이름: **국기 팔레트 (Flag Palette)**
- 핵심 가치: 국기와 색을 통해 세계 시민 교육, 문화 이해, 창의 활동을 돕는 학습 도구

## 주요 기능

- **색상 기반 국기 탐색**
  - 빨강/파랑/노랑/초록/흰색/검정 등 색상 카테고리로 국기 필터링
  - 색상 면적 기준(30% / 50% / 80%)으로 정밀 탐색
- **검색/정렬 기능**
  - 국가명 검색
  - ISO 코드, 국가명 기준 정렬
- **국가 상세 정보 확인**
  - 국가명, 수도, 대륙, 주요 색상 정보 확인
- **나만의 국기 팔레트 제작**
  - 관심 국기를 팔레트에 추가/제거
  - 팔레트 이름/메모 작성
  - JPG, PDF, 클립보드로 내보내기
  - 팔레트 파일 저장/불러오기
- **다국어 안내 콘텐츠**
  - 한국어/영어/일본어/중국어 안내 문구 제공

## 이런 분들께 추천합니다

- 초등/중등 세계시민교육 수업을 준비하는 교사
- 국기, 색채, 문화 주제로 창의 활동을 기획하는 교육자
- 나라별 상징과 시각 요소를 쉽고 재미있게 익히고 싶은 학습자

## 프로젝트 구조

이 저장소는 모노레포 구조이며, 실제 앱은 아래 경로에 포함되어 있습니다.

- `artifacts/flag-palette`: 국기 팔레트 프론트엔드 앱 (Vite + React + TypeScript)
- `lib/*`: API 스펙/클라이언트/스키마 등 공용 라이브러리
- `artifacts/api-server`: API 서버 아티팩트
